**模块与职责。**

| 代码 | 职责 |
| --- | --- |
| `JevNpcMod` | 注册实体、属性、事件、配置和服务器生命周期 |
| `entity/JevNpcEntity` | 实体、主人、背包、记忆、存档和赠送交互 |
| `behavior/ActionPlan`、`Skill` | 已绑定参数的有限动作 |
| `behavior/SkillRunner` | 持续执行、寻路、方块工作、装备、暂停恢复与本地避险 |
| `ai/NpcBrain` | 构造候选和状态，事件驱动调度，回到游戏线程应用结果 |
| `ai/JevClient` | 官网请求、响应校验、异步超时、错误脱敏 |
| `ai/DecisionGate`、`EventInbox`、`RequestBudget` | 旧结果隔离、事件合并、全服调用预算 |
| `config/` | 配置载入、默认值、参数范围和 key 来源 |
| `command/NpcCommands` | 管理命令、无 key 本地技能和定向自然语言入口 |
| `src/client/.../JevNpcClient` | 客户端人形、手持物品与盔甲渲染 |

**已知限制与待办。**

- 等待用户指定下一步测试方式，之后再进行官网调用、中文指令、战斗打断和多人场景验证。
- 任意建筑、自由对话、任意数量／装备参数和多步骤任务规划尚不在首版范围；聊天为模板，建造仅支持橡木平台。
- 地形较复杂时可能因路径不可达而失败；不挖通路、不搭脚手架、不跨维度跟随主人。
- 树木由附近树叶启发式判断，无法保证区分所有玩家木建筑；未接入第三方领地保护模组。
- 只支持一级暂停任务和最近 8 条事件；不具有完整关系数值、长期记忆检索或自主学习。
- 自定义实体没有跨 Minecraft 版本的数据迁移规则，启动会出现 `No data fixer registered` 日志；Demo 固定为 1.21.1。
- GameTest 运行在独立测试环境，不会调用付费模型，也不能证明生产服务器的延迟、吞吐或配额。

代码、配置模板、文档和测试源码均已保存在项目目录；构建缓存、开发存档、实际 key 配置和日志未纳入版本控制。
