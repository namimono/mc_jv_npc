# 决策执行链路与 HTML 查看器

日期：2026-09-25。开始实现前落盘；基于已验收的 `8b9509c`，新分支 `codex/decision-trace-html`。

## 要解决的问题

一条玩家消息会经过 Jev 路由、DeepSeek 理解、Jev 审查、目标／阶段选择、工具调用、持续动作及本地恢复。现有文本日志只保留其中部分信息，无法方便地对照“模型看到了什么、有哪些候选、返回了什么、代码最终有没有采用、世界里执行了什么”。

增加旁路记录，不增加模型请求、不改变提示词和动作选择。每次服务器运行产生独立会话，保存可追加的 JSONL 和可直接双击的 HTML，无需安装前端依赖、数据库或启动公网服务。

## 数据与关联

- 每条记录带版本、会话 ID、顺序号、时间、NPC、目标、交流 ID、span ID 与 parent ID。
- 记录输入事件、目标创建／修订／完成、授权问题、Jev 路由／审查／动作判断、DeepSeek 输入输出、工具参数／结果、身体动作的开始／暂停／恢复／取消、采集与交付进度、本地寻路恢复和实际发言。
- 模型请求保存实际发送的 JSON；响应保存服务商返回体及解析结果。另行记录采用、低置信度、过期、上下文变化、错误及实际门槛，避免把“模型选了”误作“代码执行了”。异步回调使用发起请求时的 span，不串到之后的新请求。
- Jev `answers.next_action.probabilities` 是每个候选的概率，`confidence` 是整次 Choice 的置信度，两者分别展示。缺失概率标记未返回，不能以选中项置信度推算其他值。依据：[Choice 契约](https://docs.typesafe.ai/primitives/choice)。
- 记录可观察的方法边界与结果，不记录每一 tick 或 Java 内部调用栈；不生成模型未提供的推理解释。

## 页面与落盘

中文页面提供时间线、NPC／目标／交流筛选、类型筛选、文本搜索、父子关联跳转、耗时、候选概率条形图、完整请求／响应及执行详情。可导入 JSONL 跨分段检索、导出当前筛选结果。

服务器异步写入 `logs/jev-traces/<会话>/events.jsonl`。`index.html` 是持续更新的最新分段；历史分段另存 HTML，页面可导航历史。每段限制事件数量与数据体积，防止内存和单页面无限增长；原始 JSONL 持续保留。自动刷新可关闭，筛选与选中项在刷新时保持；离线归档仍可查看。`/jev trace` 显示本机文件位置；配置 `traceEnabled` 控制是否记录。

记录器使用有界队列，写磁盘不占用服务器 tick；队列满或写入失败时明确记录／报告缺口，不阻塞 NPC，不把缺失数据伪装成完整链路。停止服务器时刷新并关闭。API key、Authorization 和常见凭据字段脱敏，HTML 把玩家／模型内容作为文本展示，不执行其中的 HTML 或脚本。页面包含聊天与模型上下文，只保存在服务器本机。

## 验收

1. 离线 HTTP 测试验证实际输入输出、完整候选概率、错误响应与密钥脱敏；不改变原有调用行为。
2. 记录器测试并发排序、父子关联、分段／导入、关闭落盘及恶意文本安全；浏览器实际操作搜索、筛选、详情与导出。
3. GameTest 检查真实方法执行产生关联记录；真实客户端验收生成实际 Jev／DeepSeek／工具链路，查看最终 HTML。
4. 构建、原有回归及独立复核通过后提交并推送分支。日志及个人运行数据不进 Git。
